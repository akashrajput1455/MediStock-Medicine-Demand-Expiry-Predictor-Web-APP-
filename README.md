# MediStock – Medicine Demand & Expiry Predictor
### MCA (Artificial Intelligence & Machine Learning) Python Mini Project

Welcome to **MediStock**!

- **Interactive Web App (Live in AI Studio Preview)**: Test all 6 modules, view dynamic charts, add/edit medicines, adjust stock, monitor expiry countdowns, run Linear Regression / Moving Average demand forecasts, and generate real CSV exports.
- **Standalone Python Flask + MySQL Project Files**: Located in the [`/MediStock`](./MediStock) directory with `app.py`, `config.py`, `database.sql`, `requirements.txt`, `README.md`, `run_project.bat`, and `run_project.ps1`.
- **1-Click Project Download**: Inside the application interface, click **"Download Python Code (.zip)"** in the sidebar or top banner to download the complete standalone zip archive directly onto your machine!

See [`MediStock/README.md`](./MediStock/README.md) for full setup instructions, MySQL configuration, and the MCA Viva Examination guide.
